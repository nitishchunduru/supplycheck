## Questions for each tester

1. Was installation successful? If not, where did it fail?
2. Which CSV validation did you try?
3. Was the output understandable and actionable?
4. Did the tool detect the issue you expected?
5. What was confusing, missing, or unnecessary?
6. Would you use it again? Why or why not?

## Evidence rules

- Count a tester only after they actually tried the project.
- Count an issue only when it exists publicly or is recorded with permission.
- Separate feedback received from fixes shipped.
- Do not publish names, company details, or private data without permission.
