# Community outreach copy

## Short post

I’ve released **SupplyCheck**, a small open-source Python CLI for validating supplier, product, material, and procurement CSV data.

It can check required fields, duplicate identifiers, basic field formats, and procurement info-record references to supplier and material master IDs. It generates JSON and Markdown reports and runs locally without an API key or database.

It’s an early-stage project, so I’m looking for a few people who work with SAP MM, procurement data, or Python CSV workflows to try the fictional examples and share honest feedback.

GitHub: https://github.com/nitishchunduru/supplycheck

Bug reports and focused suggestions are welcome. Please use fictional or anonymized data only.
