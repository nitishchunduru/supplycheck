# Security Policy

## Supported versions

Security reports are welcome for the latest published version on the default branch.

## Reporting a vulnerability

Please do not disclose exploitable vulnerabilities in public issues. Contact the repository maintainer privately through the security reporting mechanism provided by the hosting platform, if enabled.

SupplyCheck is a local CSV utility. Do not use real confidential supplier, employee, customer or financial data in public bug reports or sample files.

## Scope

SupplyCheck does not upload CSV files or send data to external services. If you discover unexpected network activity, unsafe file handling or report-writing behavior, please report it.
